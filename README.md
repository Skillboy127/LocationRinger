# Location Ringer

Location Ringer is a Flutter application that automatically manages your phone's ringer mode based on your current location. 

## Features

- **Location-Based Ringer:** Automatically switches your phone to Silent, Vibrate, or Normal mode when you enter specific geographical zones.
- **Interactive Map:** Use the built-in map interface to easily drop pins, define custom zones, and set your desired ringer mode for each location.
- **Background Service:** App runs efficiently in the background to monitor your location and adjust settings without draining your battery.
